# 実験台帳（マイナーチェンジで急所を探る）

## 決まり

1. 1チャンネルにつき、同時に変えるのは1か所だけ（変数1つ）。ほかは前の回と同じにする。2か所以上変えると、何が効いたか分からなくなる。
2. 変えた回（B）と、変えていない直前の回（A）を比べる。各3本以上そろってから判定する（1本だけだと、題材の当たり外れの方が大きい）。
3. 判定の指標は、ショートは「視聴を継続した割合」が主、「平均視聴割合」が副。長尺は「最初の30秒の維持率」と「平均視聴時間」、サムネとタイトルは「インプレッションのクリック率」。
4. 判定の基準：Bの平均がAの平均より5ポイント以上高ければ「採用」、5ポイント以上低ければ「不採用」、その間は「差なし」（どちらでもよい＝作りやすい方）。数字は公開から48時間以上たったもので比べる。
5. 採用したら、そのチャンネルの台本ルール（nazo/RULES.md、kaidan/RULES.md、claude/moso-science.md、claude/zunda-trivia-channel.md、claude/nazo-ho-hakase.md）に1行で書き足し、次の変数に進む。不採用なら元に戻して、次の変数に進む。
6. 題材は毎回変える（題材かぶり禁止のルールはそのまま）。題材の差を小さくするため、AとBで同じ系統の題材を選ぶ。
7. 判定と次の変数の選択は、日次巡回が数字をそろえた時点で行う。次の台本を書く人（Claude）は「いまの実験」の欄を見て、B側の作り方で書く。

- サムネ・タイトル：数字を入れる／入れない、顔の大きさ、文字数
