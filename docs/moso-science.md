# ずんだもんの妄想科学（台本ルール）

## 運用（2026-10-31 ゲンタさん）

- 投稿：1日1本（ゲンタさん「妄想はこの形式で1日1本出したいです」）。毎晩20:30にAPIで予約。
- 作業量（クレジット）を抑える（ゲンタさん「3Dアニメがめっちゃクレジット食うので、精緻に運用したい」）：
  - 台本は1週間分（7本）をまとめて書き、読みのチェックまで一度に済ませる。
  - 書き出しはCI（公開リポジトリなので無料）で1本ずつ順に。各回1回、直しは1回まで。
  - 確認に読むのは2秒ごとのコマ割り1枚だけ。細かいコマ割りと明るさの表は新しい場面を作った回だけ。
  - 新しい場面は週1〜2個まで。題材は今ある場面で作れるものを先に。
- モデルは使い回してよいが、アングルは回ごとに変える（ゲンタさん「モデルは使いまわしていいけどアングルとかは変えたい」）。直前の回と同じ場面を同じカメラで使うカットは作り直す（moso3d.py check で自動チェック）。
- 詳しい手順は nazo/RULES.md の「3DCG版の運用」。

## 3DCG版ショート（2026-10-31 決定。今後の妄想科学ショートはこの型）

- ゲンタさん：「素晴らしい出来です。この方針でいきます」（月の回）。「3Dずんだもんも可愛いですね」。
- 題材：「もしも〇〇がなかったら／なくなったら／〇〇だったら」系。
- 題材の選び方（10/31 ゲンタさん）：
  - 本命は「地球規模で、目に見える景色が大きく変わる」題材（「たとえば地球の氷が全部溶けたら。なんかそっち系」「太陽との位置関係とか」）。
  - 基本は、目に見えるものが消えたり変わったりする題材。
  - 「地球は絶妙なバランスで成り立っている」は味付けとして入れる。主役は景色の変化。
  - 摩擦・地軸の傾き・重力のような「普段からある概念」は、台本をもっと精密にする必要がある（何が変わるのかを最初の数秒で絵として理解させる、因果を1段ずつ見せる）。11/3〜11/5の概念系3本は予約済みのまま出し、数字で比べる。
- 型：
  1. 冒頭0〜2秒：一番インパクトのある結論のシーンとセリフ（例「1日は、6時間になるのだ」）。短く、絵が浮かぶ言い方を最優先。弱い・長い・ピンとこない結論はNG。推定に幅があれば右上に「説」。
  2. カウントダウン：計器盤タイマー（3.00→0.00、1/100秒きざみ）＋「〇〇を消すまで、3、2、1」＋3DCGで飛ぶ映像。0.00で消える。
  3. 本編：1カット1情報で畳みかける。分かりにくい因果は、短いカットを足して流れで説明する。
  4. 最後：「のだ」なしで終わり、冒頭のセリフにつながってループ。最後の絵は冒頭と同じ絵・同じカメラ。
  - 長さは30〜35秒前後。
- 映像：基本は3DCG（自前の単色ブロック。他ゲームの素材は使わない）、場合によって2D。ずんだもんの解説・ひどい目はこれまで通り。見応え最優先。止め絵を減らす。
- 点滅・急な明暗の切り替えは禁止（1秒3回未満）。昼夜は2〜3秒でゆったり。
- 字幕は2行とも黒地に白文字。効果音は従来の0.7倍。
- 仕組み：nazo/moso3d.py（check / build）、nazo/cg（three.js＋Chromium）、.github/workflows/moso3d.yml（ubuntu-24.04固定、同時に待てるのは1本）。CIで1本5〜9分。
- 事実：前提を冒頭で言う。前提で結論が変わるものは前提を合わせる。何千年もかかる変化は、すぐ起きるように言わない。

## チャンネルの位置づけ

- 「楽しく学べる」アカデミックなチャンネル。笑いは入口、見終わったあとに本物の科学の知識がひとつ残るようにする。嘘や誇張で笑いを取らない。
- 電話番号の確認がないため、カスタムサムネと関連動画は使えない（11/2 ゲンタさんが確認を試す予定）。
- 長尺（11/2 ゲンタさん「なんとか電話番号登録してサムネまでつけて、次回作を作りたい」）：太陽系回が約850再生・平均視聴5:23・ブラウジング78.8%と伸びたので、書き下ろしの長尺を続ける（10/31の「総集編だけ」から変更）。

## 科学の扱い

- 数字や現象は正確に扱う。演出はデフォルメしてよい。見方が分かれるものは「説」。
- 有名だが出典のない話（例：「ミツバチが消えたら人類は4年で滅ぶ」）は使わない。
- 数字と出典は説明欄に。計算値は「計算値」と明記。
- 読み：src/yomi_gate.py の関門を必ず通す（読みが2通りある語、「は、」のワ読みも自動チェック）。

## 長尺 第2回「ずんだもんが7つの時代に移住してみた結果」（2026-11-02）

- 方針（ゲンタさん）：見た人がずんだもんの怠惰さや自暴自棄に共感しつつ、最後はこの星やいまの環境を大切にしようと思える話。「ここではないどこか」「いまではないいつか」を求める無いものねだり。過去に戻るなどSF要素も可。
- テーマは表に出さない（ゲンタさん「視聴者に感じ取ってもらうもの」）。教訓のセリフは言わせない。最後は部屋で蛇口の水を飲み「……ここでいいのだ」。

- 外から見える形は第1回にそろえる（構成を大きく変えず再現性を見る）：タイトルに「移住」、データカード、判定「移住：×」、ランキング（第1位＝いまの部屋）。
