# 物理シミュレーション＋心地よい音の制作仕様

**心地よさの作業定義**　スマホの画面で主役の動きを目で追え、次の反射や到着を予期でき、見えた出来事に対応する音が短いフレーズとして聞こえ、最後に動きと音がそろって解決する感覚。作り手は、画面上の速度・局所密度・発音密度・同期誤差・停止率を記録し、オーナーは「追いやすさ」「音の軽さ」「待たされなさ」「終点の気持ちよさ」を各1〜5で評価する。数値は初回試作用の仮説で、評価の代用にはしない。

## 観測と根拠

- Aの評価は「論外」。制作メモでは後半に数百個が底に積もる。Bの評価は「ボールのスピードが速すぎる、ポイントで止まりすぎ」。Bは移動1.33秒と停止0.50秒の反復なので、停止率は約27%。両作の書き出し素材とイベントログは未計測。挙げられた参考ショートの実測値も使っていない。
- 反射の瞬間に近い音は、動く物体がぶつかって見えるかどうかや同期感に影響する。円盤を使った実験では、主観的な同期のピークは接触の約16 ms後だった。 [Vroomen & Keetels](https://pubmed.ncbi.nlm.nih.gov/32569946/)
- 衝撃音の数と間隔のばらつきは、音が個々の跳ね返りとして聞こえるか、転がりに近く聞こえるかに影響する。色・向き・コントラストの局所的なばらつきは、視覚的な混雑の指標に使われる。 [跳ね返りの音の実験](https://doi.org/10.1080/25742442.2022.2143201) [Rosenholtzら](https://www.mit.edu/~yzli/clutter.pdf)
- 和音列を使った研究では、次の和音の不確実性と、実際に鳴った和音の意外性が組み合わさって快さの評価に関係した。 [Cheungら](https://pubmed.ncbi.nlm.nih.gov/31708393/)
- 理想楕円では片方の焦点から出た点粒子は鏡面反射で他方の焦点を通り、経路長はどの方向も長軸長 (2a)。同じ速さで同時に出せば同時に到着する。 [American Mathematical Societyの教材](https://www.ams.org/bookstore/pspdf/amstext-44-prev.pdf)

## 仮説としての推奨数値

画面高さを H、画面幅を W とする。基準は9:16、1080×1920、60 fps。速度はカメラ適用後の球中心の移動距離を H と秒で割る。反射フレームは経路を接触点で分割し、停止区間は速度集計から外して別集計する。p95は移動中の球×フレームの95パーセンタイル。発音数は全楽器のノートオン数で、3音の和音は3発。リバーブの尾は発音数と同時発音数の集計から外し、最終ミックスの計測に含める。

| 要素 | 初回の推奨範囲と測り方 |
|---|---|
| 速さ | 主役の移動時中央値15〜28% H/秒、p95は35% H/秒以下。直径0.8〜1.4% H。速い場面でも主役の1フレーム移動を直径の半分以下に。 |
| リズム | 定拍の企画は75〜105 BPM。四分音符571〜800 ms、八分音符286〜400 ms。主拍は見える出来事から作り、物理の衝突時刻を後から拍に丸める場合も同期条件を優先する。 |
| 発音の密度 | 曲中の移動区間平均2〜5発/秒。任意の1秒で通常6発以下、終止だけ8発以下。通常の単音間隔120 ms以上。同じ約30 msに来る候補は代表1イベントに束ねる。束ねた到着は単音または設計済みの2〜3音。同時に鳴るドライ音は通常2声以下、終止3声以下（発音から包絡がピーク比−40 dBになるまで）。 |
| 映像と音の同期 | 書き出し後の音の立ち上がりは視覚イベントより0〜20 ms後を狙う。絶対誤差のp95は25 ms以下、主役の着地・集合・終止はすべて25 ms以下。音の基準はドライ包絡がピークの10%に達した時点。 |
| 音色と残響 | 木琴系または柔らかいマレット系を主役1種、区切りに補助1種。アタック4〜12 ms（10%→90%）、ピークから−40 dBまで140〜320 ms。残響はRT60 0.25〜0.55秒、ウェット信号は同じ音のドライ信号比−22〜−16 dB RMS。 |
| 音程 | 1フレーズ3〜5音種を固定。初期音域はMIDI 60〜76。主旋律の隣接音は0〜5半音を基本とし、5半音超の跳躍は4〜8イベントに1回まで。球ID・ゲート番号・通過順など再現可能な規則で音列を決め、同じモチーフを2〜3回反復。集合は主音か事前に決めた和音に解決。 |
| 音量の山 | 主音色の通常ノートのゲイン差は3 dB以内。集合音は通常音より短時間の音量の山を2〜4 dB上げる。代表通常音と集合音の開始後各100 msのミックスRMSで比較。完成音声は−20〜−16 LUFS-I、最大−1.5 dBTP以下で試す。計測法はBS.1770準拠。 [EBUの計測ガイド](https://tech.ebu.ch/docs/tech/tech3343.pdf) |
| 間 | 反復途中の完全停止は0〜100 ms、周期に占める停止は5%以下。強調は0.18〜0.30秒の発光や減速で表現し、物体の移動は続ける。終止から次の起点までは0.3〜0.6秒を試す。 |
| 予測と変化 | 最初の1〜2秒でルールの手掛かりを出す。同じ規則が見える反復を2〜3回置き、4〜8イベントごとに1つだけ変化。速度・配色・音程を同時に変えるのは最後の集合に集約する。 |
| 視覚の密度 | 通常は同時に追わせる球4〜16個。軌跡は0.3〜0.6秒で消し、幅0.08〜0.16% H。輪や文字を除いた球・軌跡の描画マスク（背景合成前のα≥0.15）の和集合を画面の3〜15%程度、上限20%。運動領域を覆う矩形の固定4×4分割で、各セルの占有率は35%以下を目安にし、集合の前後100 msは別集計する。 |
| 色とカメラ | 背景1色、球と軌跡は主色1〜2色、イベントの差し色1色。初回は背景と球中心の相対輝度比3:1以上、発光の外周は球半径の0.5倍以内。固定カメラ、運動外接矩形の幅65〜85% Wを目安にし、主役が字幕や投稿画面のUIと重ならない位置に置く。全画面フラッシュ0回。 |
| 終わりとループ | 主イベントを最後の0.3〜0.6秒の入口に置く。戻せる構造なら頭と末尾の継ぎ目で主役の変位を1フレーム分以内、速度差10% H/秒以内にする。ループ音声の継ぎ目は波形の不連続をフルスケールの0.01以下にする。残響は周期先頭へ折り返すか、終端まで減衰させる。閉じない企画は終止音と0.3〜0.6秒の余韻で一区切りにする。 |

## Aが「論外」になった原因の推定

| 観測 | 仮説と切り分け |
|---|---|
| g=1.6、初速1.8、球同士の反発0.92、壁は完全弾性。4個から500個に増える。 | 問題の第一候補は底への局所集中。重力で落下が偏り、球同士の衝突で法線方向の相対運動エネルギーが失われるため、壁が弾性的でも密集は起こりうる。まず同じ球の初期条件と乱数シードで、増殖なし・16個固定の g=1.6／0.4／0 を無音比較する。次に g=1.6 のまま増殖上限16／32／500を比べ、底のセル占有率と球の追いやすさを見る。上限16・32の版は同じ時刻のカウント演出で長さをそろえ、破裂演出は比較から外す。 |
| 壁反射が発音候補で最大14発/秒。金の点には鈴、最後にはアルペジオが加わる。実発音数や間隔分布は未計測。 | 上限付近では平均70 ms程度で次の音が来るため、散発的な衝突と残響がまとまって聞こえ、どの球の音か追いにくい可能性。映像固定で現行音と、120 msの間引き・毎秒6発上限の版を、同じLUFS-Iに合わせて比較する。金の点と終止を優先し、同群では目立つ球の反射を採る。 |
| 音高は角度で和音内から選び、2小節ごとに和音が切り替わる。原色を個体ごとに増やし光彩も付く。 | 角度→音高は規則的でも、球が混み合うと視聴者には音列が不規則に聞こえる可能性。和音進行の良否はこの評価だけでは判定できない。同じ発音時刻と音色で、現行音高と、イベント順に MIDI 67・69・71・69 を反復する版を比較する。配色は別に、同じ映像で原色多色と主色2＋金1を比較する。 |
| 約34秒で輪が割れ、上昇アルペジオが鳴る。 | 結末までに混雑が長く続き、音の解決よりピークが印象に残る可能性。同じ破裂映像で、上昇アルペジオと主音1発＋0.4秒の減衰を比較する。 |

最初の試作は16球上限・g=0.4・色3種・主役の反射だけ発音。因果を調べる比較は上のように一項目ずつ変える。

## Bの修正値

- **第一候補は移動2.20秒＋停止0.067秒（60 fpsで4フレーム）**。画角が同じなら速度は元の60.5%、停止率は約2.9%。比較用に移動2.00秒＋停止0.10秒、移動2.40秒＋停止0秒も作る。速度だけ検証する回では停止を4フレームに固定し、停止だけ検証する回では移動2.20秒に固定する。
- 長軸を横に44% H（約78% W）、短軸を30% Hにすると、第一候補の一定速は20% H/秒。現行画角を使う場合は長軸の画面上の長さを H で割り、移動時間で割った値を確認する。重力0、反発1、球同士の衝突0。球中心を点粒子として理想楕円で反射させ、描画の直径は1% Hとする。
- 焦点の発光は到着から0.22秒で消し、4フレーム後の再出発に重ねる。到着音は MIDI 72 を1発。壁は1区間に目立つ反射3回までとし、時刻順に MIDI 60・64・67。反射が近い場合は120 ms間隔を優先し、到着直前120 msは到着音を優先する。この案は4発をすべて使っても約1.8発/秒なので、焦点を聞き取りやすくするための低密度の例外として試す。
- 初回は5→10→16個で上限をかける。軌跡は0.4秒・線幅0.10% H。まず球数と音を同じにした速度・停止比較を通し、その後に密度と音を調整する。全方向の代表性は初回5本を72度間隔、以降は各回の本数で等角度にする。

## 決定論的な企画5案

以下で座標・距離は H 単位。各案とも固定カメラ、マレットのアタック8 ms、通常の減衰は−40 dBまで約180 ms。終点だけ減衰を約280 msに伸ばす。

| 企画 | 運動設定 | 発音設計 |
|---|---|---|
| 1. 等間隔のゲートを通る往復球 | 横0.36の直線を球1個が0.18 H/秒で往復。両端で反発1、重力0。ゲートは0.00・0.09・0.18・0.27・0.36。4秒周期を5周。 | 左から MIDI 60・62・64・67・69。折り返しも通過ごとに1発、同一端点の二重発音を除く。0.5秒ごとで2発/秒、最後は60。 |
| 2. 同じ出口に着く5本のレール | 5本のレールで経路長0.30・0.35・0.40・0.45・0.50。一定速0.20 H/秒、発車は1.00・0.75・0.50・0.25・0秒の順。全車2.50秒着。共通の始点 (−0.14, 0)、出口 (0.14, 0)。経路長 L ごとに中継点を (0, ±√((L/2)²−0.14²)) とし、符号は短い順に交互。折れ線を弧長で評価し、重力と相互衝突は0。3秒周期で左右反転を交互に6回。 | 発車順に MIDI 60・62・64・67・69。共通到着は72を1発、5車分を束ねる。最大4発/秒。 |
| 3. 位相がそろう3つの回転リング | 同心リング半径0.08・0.12・0.16、周期2・3・4秒。速さはすべて約0.251 H/秒。全点を頂点から出し、12秒で再集合、24秒で終止。 | 各リングの頂点に MIDI 60・64・67 を割り当てる。中間の同時通過は低い側を1発、12秒の倍数の集合は3音を1イベントで発音。0秒の発音はループ境界で重複除去。 |
| 4. 位相をずらした振動子の輪唱 | 横に8個を中心間隔0.05で並べ、縦振動 (y_i=0.055\cos(2\pi(t-0.24i)/1.92))、i=0〜7。最大約18% H/秒。上端での発光が左から右へ伝わる。10周期で19.2秒。 | 上端だけ鳴らし、MIDI 60・62・64・67・69・67・64・62 を周期ごとに反復。平均約4.17発/秒。最後の継ぎ目に左端の60が戻る。 |
| 5. 1球の反射音が上下で応答する | 幅0.36・高さ0.24の矩形。左下から速度成分 ((0.18,0.16)) H/秒で発射。重力0、壁反発1。左右壁は2秒間隔、上下壁は1.5秒間隔。12秒で位置と進行方向が周期復帰。 | 左・右壁は音高60・67、下・上壁は64・69。角の同時衝突は6秒で MIDI 60・64、12秒の境界で60の1発。区間中の発音密度が低い案なので、無音間隔の長さを独立して評価する。 |

## 書き出し前後の機械チェック

- [ ] 物理イベントと音のログに時刻・球ID・イベント種別・位置・MIDI音高・ゲイン・採否を残す。固定初期条件と固定刻み（例 240 Hz）で2回実行し、時刻・並び・数を比較する。同時刻の優先順を固定する。焦点到着や壁接触には解析解かステップ内の接触時刻補間を使う。
- [ ] 書き出し後のフレーム時刻と復号音声で同期差を再計算する。代表イベントの欠落・二重発音を検出し、半開区間 [t, t+1秒) の移動窓で最大発音数、120 ms未満の単音間隔、同時発音数、音程の跳躍、音量の山を集計する。和音と指定の終止は明示的に例外フラグを付ける。
- [ ] 球中心を投影して移動速度の中央値とp95、1フレーム移動量、停止率を計算する。Bは焦点到着時の最大中心誤差1 px以下、同時到着の時刻差1フレーム以内。描画マスクで球数、画面全体・各セルの占有率と連続超過時間を出す。
- [ ] 背景と球の輝度比、パレット数、軌跡寿命、カメラ座標、文字やUI用の除外領域との交差、全画面フラッシュ回数を確認する。発光の強いシーンでは局所的な明暗反転も確認する。 [W3Cのフラッシュ定義](https://w3c.github.io/wcag/understanding/three-flashes)
- [ ] 最終エンコードを復号してLUFS-IとdBTPを測る。ループは終端と先頭を連結して、位置・進行方向・速度および音声の継ぎ目を確認する。旧版と比較する場合はLUFS-Iの差を0.5 LU以内にそろえる。
- [ ] 企画ごとに意図した数値の例外を記録する。オーナー比較は順序を入れ替え、同じ端末・音量で評価する。4項目のうち狙った評価が1点以上上がり、他項目が下がらない版を採用候補とする。評価の根拠になった秒数も残し、次の試作で数値を更新する。
