## 見る点

模様が残る型（歯車の花・番号の何倍・バラ曲線・集まる線 など）
- 最後の絵が密か。線や点が細かく重なって面になっているか。目安：`vet.py fp` の「埋まり」が 25% 以上

どの型でも
- 出だしから動いているか。終わりまで止まって見える時間がないか
- 音が1つずつ気持ちよく鳴り、和音に収まっているか（石・カロの音、和音を意識）
- 字や絵が画面からはみ出していないか、重なっていないか
- 法則どおりに動いているか（作為的な仕掛けにしない。ドミノはもたれかかって倒れる など）
- 説明文の数字が、動画の中の数字と合っているか

## 音色（持ち主 2026-11-27）
- 「音がキンキンしてる。もうすこしカランコロンって感じのカリンバっぽい心地よい音色」「ブラーエコーもかけすぎない」
- 「モロカノンというよりカノン進行」
- 「音はもっと乾いたカロっ(飴玉を口で転がすような)音がいい。音階はカノン」
- 同日、聞き比べ（output/karo_ab.mp4）への返事：「電子音ぽすぎるんだよな。もっと物理的な音がいいというか。この中なら4が近い　二度うちは違う感じがする。恣意的な感じがする」
  - 二度打ち（カロッの「ッ」を別の音で足す）はしない。1つの当たりに、音は1つ
  - 鳴らすのは、絵の中で物が当たった瞬間だけ。飾りの音（板が消える時の追加の音、決着の旋律など）を足さない
  - 波を別々に作って足す作り方（音程が上から落ちる仕掛け、あとから足す雑音）をやめ、当たる力の短い山から、物の響きを全部いっせいに鳴らす（`tools/kalimba.py` の `knock`）
- 聞き比べ（output/oto_ab2.mp4：1＝前の4、2＝木、3＝竹、4＝空洞のある木）への返事：「2.3.4全部いいローテでいい」
  - 材質は `knock` の `wood`（木の板）→ `bamboo`（竹の板）→ `hollow`（空洞のある木）を、動画1本ごとに順番に回す。余韻は 0.03〜0.3 秒、残響ほぼなし
  - 次の材質は `python3 tools/trendkit.py nextmat`。使った材質は `nazo/trend/mat_log.txt` に1行足す（tiles1＝木）。日本語版と英語版は同じ材質
- 音の高さはカノン進行（D A Bm F#m G D G A）の和音の音。当たった瞬間に鳴らす。当たりの強さは、絵の中の速さに合わせる（低く跳ねる玉は弱い）
- 数値の目安：5kHz より上は全体の 3% 以下（`tools/trend/check.py`）。耳では確かめられないので、新しい音色は聞き比べを持ち主に送る

## 見た目の質（持ち主 2026-11-27「テクスチャと軌跡が安っぽい」）
- 言われた絵：ベタ塗りの四角に線を引いただけの板、同じ太さ・同じ明るさの細い線で引いた軌跡（tiles1 の最初の版）
- 物には材質を持たせる：木なら木目・1枚ごとの色の差・角の丸み・上の面取りの明るさ。玉は飴玉（光が中を通り、反対側の内側が明るい）。`tools/trendkit.py` の `wood_stack`・`sprite`
- 軌跡は、ペンで引いた線にしない：長時間露光の残像（そこにいた時間が長い所ほど明るい＝弧のてっぺんが明るい）＋玉のすぐ後ろの短くやわらかい光。`Trail`
- 動きは1画素ずつカクカクさせない（小数の位置で置く）。速い玉は、1コマの中の動きを平均して流す（`blit_mb`）
- 当たった所には、当たった物の色が映る。はがれた物は、回りながら落ちる。物が動く理由（ばね・重さ）を絵にする
- ふちは必ずなめらかに（大きく描いて縮める）。なだらかな色には粒子をまぜて段々を出さない（`to_frame(…, grain=コマ番号)`）
- 光らせすぎない（11/23「下品な光になりすぎないように」）。足した光は、重なっても白く飛ばない混ぜ方にする
- 確かめる時は、縮小した全体だけでなく、等倍の切り出しも見る

## 狙い（持ち主 11/28。いちばん上に置く基準）
- 視聴継続率は、いつも 70% 以上を目指す
- 冒頭から、わかりやすい変化（やりすぎではない）か、何かが動いていること。最初のコマから動いている／最初の1秒で「何が起きるか」が見える
- オチ：結果はやんわり想像がつくが、本当にその通りになるかはわからない、くらいの好奇心を狙う（例：青が勝ちそう → でも黒が逆転するかも／全部入りそう → 1個こぼれる）。題名と画面の問いで、その予想を立たせる
- チャンネルのエッセンス：和音、音の心地よさ、瞑想感。どの動画も、ここを外さない
- 画面の文字は最低限（11/28「文字情報も最低限でいいから」）。問いの1行と、必要なら数（カウンター）だけ。説明の2行目・途中の字幕・結末の字幕は、なくても伝わるなら入れない。くわしいことは説明欄に書く

## 見切れない置き方（持ち主 11/28「英語版見切れないようにして」）
- スマホ（縦長の画面）では、ショートは高さに合わせて表示されるので、左右が約100pxずつ切れる。さらに右下には「いいね」などのボタンが重なる
