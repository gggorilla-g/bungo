Privacy Policy — Tankobu Channel Uploader

Last updated: October 18, 2026

1. About this tool

Tankobu Channel Uploader is a personal tool used by Genta Yamasaki (individual) only to upload videos he produced himself to YouTube channels he owns.

2. YouTube API Services

This tool uses YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy apply.

3. Information collected

This tool does not access third-party accounts or data, and does not collect, use, or share any personal information of other people. The only OAuth scope requested is youtube.upload, used for the operator's own channels.

4. Storage of credentials

The OAuth token for the operator's own channels is stored only in an encrypted secret store (GitHub Actions Secrets) and is used only to upload videos and set thumbnails. It is not shared with anyone. No other data obtained through YouTube API Services is stored.

5. Deletion and revoking access

Access can be revoked at any time from Google security settings: https://security.google.com/settings/security/permissions. Once revoked, the stored token can no longer be used, and it is deleted from the secret store.
