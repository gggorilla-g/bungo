Tankobu Channel Uploader

Tankobu Channel Uploader is a personal tool operated by Genta Yamasaki (individual). It uploads original narrated videos that I produce to YouTube channels that I own.

What it does

  • Renders each video in an automated pipeline (GitHub Actions).
  • Uploads the finished video to my own YouTube channel with a scheduled publish time (YouTube Data API: videos.insert).
  • Sets a custom thumbnail (YouTube Data API: thumbnails.set).

The only OAuth scope requested is https://www.googleapis.com/auth/youtube.upload. The tool has no public user interface, is not offered to anyone else, and does not access any other user's account or data.
