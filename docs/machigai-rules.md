# 動く間違い探し「どこちがう？」の決まり（雑学チャンネル）

nazo/RULES.md の該当部分の写し（2026-11-15 時点）。

## 形式
- 11/14 ドライブ版を追加（nazo/cg/scene.js の drive）。p.mode="front" で、車の前から1カットで撮り続ける（11/15 ゲンタさん「カットは割らずに風景が流れていく感じ。ずんだもんは正面」）。A と B は上下に並べる。p.seed で道ばたの並びが変わる。
- 締めの一言（11/15 ゲンタさん「全部見つけたら天才なのだはやめましょう」）：「天才なのだ」は使わない。既定は「答えは、説明欄なのだ！」。タイトルも「〜で見つけたら天才」をやめて「〜で見つけられる？」にする。
- 背景と場面に毎回バリエーションをつける（11/15 ゲンタさん「今後は背景やシーンにバリエーションもたせたい」）。直前の回と同じ場所・同じ季節・同じ時間帯を続けない。同じドライブでも、海沿い・雪道・夕方・夜の町のように景色を変える。
- 違いの種類（11/15 ゲンタさん「赤青の違いみたいな感じでマンネリ化してる」）：色を変えるだけの違いは1本に1つまで（なるべく0）。ある／ない、形、数、大きさ、動き、向き・ポーズで作る。
- カメラ（11/15 ゲンタさん「縦構図より横移動のカット割ったやつの方が評判いい」）：ドライブは横から並走するカットを割る形（scene=drive2：横・低い望遠・高い横の3カット）を基本にする。正面1カット（drive の mode=front）は使わない。drive2 は biome で場面を変える（sea 海沿い／snow 雪道／town 夕方の町）。

## 間違い探しの作り方（11/15 ゲンタさん「間違い探しを学んで」→ 調べてまとめた）
出典：まちがいさがしクリエイター funeno さんの note「まちがいさがし制作のコツ」、サイゼリヤの間違い探しの作者（山崎秀昭さん）を紹介した note。
- 1つはだれが見てもわかる違いを入れる（探し続ける気にさせる）。残りに難しいものをまぜる（funeno さん）。→ 5つなら「やさしい1・ふつう2〜3・むずかしい1〜2」。やさしい違いは最初のカットに置く。
- 違いのパターンは「色・向き・数・長さ」など約15種類あり、組み合わせて作る（サイゼリヤの作者）。→ 1本の中で同じ種類を2回使わない。色は1つまで。種類の候補：ある／ない、ふえる、数、大きさ・長さ、形、向き、ポーズ、動く／止まる、位置、入れかわり、模様、表情。
- 違いがありそうな場所にあえて手を入れず、ひっかける（同）。→ 目立つ動き（手をふる人、回る風車など）は A と B で同じにして、おとりにする。
- 絵の中に人物の関係や小さな話を持たせる。例：片方だけリンゴがあり、横の人が食べたように見える（同）。→ 違いの1つは「話のある違い」にする（例：ベンチの子のアイスが B では食べ終わっている、犬がボールをくわえている／いない）。
- 動く間違い探しで足すこと（自分たちの判断）：違いは画面に2.5秒以上映るようにする。むずかしい違いは、遠くの背景（流れが遅い）か、カットの頭に置く。
- 自分たちの数字（11/14 観測）：間違い探しの継続率31〜45%は、名前系の雑学（9〜26%）より高い。再生は 672〜1,270回。
