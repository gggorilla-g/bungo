# 物理・数学シミュレーション Shorts ネタ帳

初回は **放物線の焦点、サイクロイドの同着、楕円の同着** の順で制作する案。最初の1秒で出発点と判定点を見せ、終盤に「点へ集まる」「異なる高さから同時に来る」「反射位置が違っても同時に来る」という別々の答えを見せる。4本目の閉軌道と5本目の逆転レースで、同じ画面構成が別の問いにも通用するかを見る。順位は、答えの見えやすさ、既存コードの再利用、終盤の見せ場を基準にした制作上の提案。

## 制作案の共通設定

- 画面は縦9:16。座標と速度の単位は表示用の u、u/秒。場面を収めてから画面に等比拡縮する。球の描画直径は画面幅の0.6～1.0%。反射系の計算は点粒子で、接触位置は球の中心で判定する。独立球同士はすり抜ける。
- 軌跡は低い不透明度で残し、同じ色の再通過で飽和しすぎないよう描画の上限を設ける。集合点や判定ゲートでは球を通過させる。重力型は底で折り返すレールか画面外への排出路を使う。画面に出す文字は各言語版の問い1行と数値だけ。
- 増やす回は原則として一波ごとに 4→6→9→13 程度。同期・閉軌道・衝突回数が主役の回は固定数。レースの増加は下記の整数列に従う。
- Python で接触時刻を求め、各球の各接触に自作の短い音を1声ずつ、48 kHz の最寄りサンプルに置く。数学上の交点や判定線は画面にゲートとして描き、通過の瞬間に発音する。2球衝突では各球に1声、衝突カウンターは物理イベントとして1加算。同時刻の音は全声を加算し、密集時のピークに合わせて混合全体のゲインを下げる。低い衝撃音を使わず、基音は原則 C5・D5・E5・G5・A5 の短い合成音。表の「順」はこの5音を巡回する割り当て。
- 下表はモデルの結果と制作設定。再生や登録の予測は後段の憶測に記載する。

### レース3案の共通仕様と計算結果

各色に耐久値が同じ10枚の板を置き、手前から順に壊す。#5 は板ごとの必要ヒット数を 1,2,3,4,5,5,6,7,8,9、#15 は 1,2,3,4,5,6,7,8,10,11、#16 は 2,3,4,5,6,7,8,10,14,16 とする。各球の最初の板接触だけを得点対象にして、横の排出路へ流す。2列とも発射点から板までの経路長を60 uにそろえ、初速0・g=30で2秒後にヒットする。板ごとに発射位置と描画レーンを対応させ、行き先は到着順から事前に確定する。接触の同時処理は色別、各色の球番号は0始まり。第n波の第j球を 1+4n+0.1j 秒に発射し、3+4n+0.1j 秒で得点。勝敗確定後も発射済みの球を動かし、勝者側の残りは同じ到着面の出口ゲートに鳴らして排出する。表の累積は板の上限を適用する前の到着数で、勝敗確定後の値は比較用。

## 10本ずつのシリーズ案

1. **同時に着く放物線**（#1）。焦点距離 f を 24, 28, 32, 36, 40, 44, 48, 52, 56, 60 の10通りにする。x²=4fy、発射線 y=288−f、描画範囲 x=±1.8f。速度32、投入時刻と球数を固定して毎回9秒で合流させる。曲面の深さと反射線の開き方が変わる。
2. **何反射で閉じる長方形**（#4）。正規化した往復数 (p,q) を (1,1),(1,2),(1,3),(2,1),(2,3),(3,1),(3,2),(3,4),(4,1),(4,3) とする。長方形と始点を固定し、(2pW,2qH)/30 を速度ベクトルにする。表示上の反射数は 2(p+q)。角衝突の時刻が重ならないことを各設定でチェックする。
3. **先に板を割る色**（#5・#15・#16）。共通仕様の青6・橙2+floor(n(n+1)/4)を使い、目標値を49,50,51,52,53,54,55,56の8本に設定。n=6で42対40、n=7で48対56なので全8条件で同じ波に逆転と決着が入る。最初の9枚の合計41を固定し、最後の板の耐久値を8～15に調整する。残り2本は #15 と #16 の設定。投稿順では同じ勝ち色が続きすぎないよう、青・橙の割り当てを交互に反転する。

## 避ける表現と演出

- **権利**。参考動画の画面、効果音、曲、ロゴ、固有の配色やレイアウトを流用しない。流行曲のメロディを自作音でなぞる使い方も避ける。音は自作合成、図形は数式から描画する。
- **安全・見やすさ**。同期時に全画面を強く光らせたり連続点滅させたりしない。音の同時加算で飛び出すピーク、低い衝撃音、密集で軌跡が読めなくなる演出を避ける。重力型では底に積もる設計を外す。重量物の衝突は画面内のモデルで扱う。
- **観測とモデル**。等時・反射・衝突数は該当する初期条件と理想化の範囲で扱う。焦点に停止する絵、普通の重力下で光線と同じ放物線反射が起きるような絵、鏡面と球中心の接触点がずれる描画を避ける。πの回のカウンターは衝突回数を整数表示し、3.1秒や速度の値に見える表記を避ける。時間伸縮などの条件は動画の説明欄に記載できる。
- **有限例と一般性**。コラッツ回は「この4つ」と説明欄に書く。ガルトン回は全経路を各1回通した二項係数の可視化。ウラムのらせんは素数判定の結果を示し、線上の全点や先の範囲を断定しない。閉軌道は座標に加えて進行方向も比較する。
- **勝負の見せ方**。色ごとのレーン長・接触時の得点・各板の耐久値をそろえる。累積で追い抜いた後に勝利条件を差し替える演出は避ける。
