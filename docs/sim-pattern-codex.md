# ボールの動きと音で見せる Shorts のパターン辞典

次の試作は「円を転がすと直線が出る」「真下に放した球と、横に投げた球が同着する」「境界を少し傾けると光が出なくなる」の順。どれも冒頭で判定場所を置けて、答えを無音でも読める。既存の楕円回からは、小球・ゆっくりした増加・残る軌跡・球ごとの音を引き継ぐ。以下の秒数、優先順位、配色は制作仮説。

## 1. 観測

### Web で確認した事実

- YouTube Studio の Shorts 指標には「視聴を継続」「エンゲージ ビュー」「平均視聴率」「登録者」がある。エンゲージ ビューの定義ではループを除く。公開再生数と視聴継続・登録への転換は別の指標として扱える。[YouTube 公式ヘルプ](https://support.google.com/youtube/answer/12220281)
- 同じ場所で放した球でも、水平速度だけが異なる場合、理想的な一様重力下では鉛直運動は同じ。屈折と全反射の境目は屈折率と入射角で決まる。制作案の個別設定と答えは第4節に記載した。[OpenStax・投射運動][projectile]・[OpenStax・屈折][optics]

## 3. 当たり外れの分かれ目（憶測）

「152万対1万」は要因を考えるための例。比較対象の1万回の動画は特定されていない。M1の152万はM0の直近48本中央値4.1万の約37倍だが、M1がその48本に含まれるかと公開後の経過日は不明。

## 4. 新しい30本（制作仮説）

順序は反直感の強さ、決着の読みやすさ、既存素材での試作しやすさで決めた。意外さは視聴者調査前の見立て。難度の低は座標式・経路再生、中は交点計算・描画の工夫、高は群制御や可視化の調整を含む。下の出典は原理の出典で、秒数・色・画面上のゲートは自社設定。

物理は解析式から接触時刻を求める。構図を正規化してから、全体に同じ時間倍率を掛けて減速する。作図回は記載順で球を送り、各球は指定の点の手前から等速で入り、通過後も進める。指定のないマーカー間隔は0.5秒、波間は4秒。計算上の点や線で鳴らす場合は目に見える小さな判定ゲートを置く。軌跡のみ残し、出口で球を滞留させない。
