## コマを見て書いたしくみ（4本）

### A 鍵盤サバイバル（2IJV5XgZRFU）
- 決まり：8色の玉が、ピアノの鍵盤の上で跳ねつづける。鍵盤が1枚ずつ割れて落ち、穴に落ちた色は脱落。最後まで跳ねていた色が勝ち。
- 画面の文字：上に問い（どの色が残る？）。途中で「GREEN OUT」「HALF GONE」「DOUBLE OUT」「FINAL 2」と状況が出る。下に残っている色の一覧。
- 結末：最後の2色の一騎打ち → 1色。
- うちで作れるか：作れる。跳ねるたびにその鍵盤の音を鳴らせるので、「当たった時刻と音を合わせる」の決まりにそのまま合う。
- うちの既出との重なり：玉レース（race1）と同じ「勝ち抜き」だが、決まりは別（鍵盤が減る）。絵は鍵盤の遠近をまねず、自前の並び（たとえば木琴の板を横一列）にする。
- 11/27 制作：tiles1（`tools/tiles.py`）。決まりは自前に変えた：板14枚の厚さが1〜14とぜんぶ違い、ふむたびに1つうすくなる。1色おちるたびに、はねる高さが下がって速くなる。

### B つぶすと4倍（HOJSE1xN520）
- 決まり：円の左右から三角のあごが閉じる。つぶされるたびに、玉1個が4個になる。1 → 4 → 16 → 64 → 256 → … → 2,900。
- 結末：数が増えて円が割れ、玉があふれ出る。説明文「How long until the circle breaks」。
- うちで作れるか：作れる（pymunk。あごは動く壁）。光の線（laser1）と同じ「倍々」だが、結末（器が割れる）が違う。
- 注意：登録者114人のチャンネルで1.9万回。

### C 跳ねるたびに大きく（-IgeBkxQ41s）
- 決まり：円の中で玉が跳ね、通った跡が色の帯で残る。跳ねるたびに玉が大きくなる。
- 結末：玉が円いっぱいになり、円がくだける。
- うちで作れるか：作れる。跳ねる間隔がだんだん短くなるので、途中で拍が上がる。
- 注意：よくある型。題名に中身が書かれていない（「hits different」）。

### D 脱出すると2個（s1XXOljbprk）
- 決まり：すき間のある輪が回っている。玉がすき間から外に出るたびに、中に2個生まれる。1個 → 55個（50秒）。
- 画面の文字：上に題と問い（最後は何個になる？）、下に今の個数。
- うちで作れるか：作れる。
- 注意：日本語。登録者6人で5,480回。うちの倍々（dots3・laser1）と近いので、出すなら決まりを1つ足す（たとえば、出た玉の色で音の高さが決まる）。
