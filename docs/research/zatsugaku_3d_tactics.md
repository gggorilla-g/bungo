**推測（転用する4つの型）**

| 型 | カメラと画面 | 題名・サムネの制作案 |
|---|---|---|
| 地形・位置関係 | 斜め俯瞰で立体感、真上の固定画で前後比較。赤青の位置関係を保つ | 題名は固有名＋ひとつの疑問。サムネは地形の特徴ひとつに短い語。「なぜ星形？」 |
| 積層・復元 | 同じ角度で地面を断面にし、時代が違う層を順に点灯 | 題名は場所＋隠れていたもの。サムネは上下2層と「地下に旧城」 |
| 寄り・断面 | 最初に全体、次に見えない部分へ寄り、最後に全体へ戻る | 題名は具体物＋見慣れない現象。サムネは断面1つ。「屋根に穴」 |
| 仮定・比較 | 変える条件を一つにして同じカメラ位置で並べる | 題名の前半に「もし」。画面に「模型の比較」を出し、史実との違いを示す |

英語例は題名で How / Why / Would や、事件と意外な発見の組み合わせを使う。日本語例は「1万人」のような具体数や、「豊臣大坂城」のような固有名、「組み上がる」のような画面の動きを題名に入れている。**推測**　当チャンネルでは絵文字よりも、スマホ上で読める固有名・短い疑問と、縮小しても判別できる形を先に試す。

## 3. スワイプと視聴継続への対策

**事実（YouTube公式）**

- YouTube公式ブログ掲載のCreator Insider対談で、制作者Jenny Hoyosは最初の1秒を重視し、驚きから興味を引き、最後に期待を満たすという考え方を説明。Shortsフィードとチャンネルページでは、サムネが担う役割も違う。1秒は制作者の実践知。[YouTube公式ブログ](https://blog.youtube/creator-and-artist-stories/youtube-shorts-deep-dive/)
- Shortsの評価には視聴者が視聴を選んだ割合、平均視聴時間、平均再生率、評価・視聴後のアンケートなどが使われる。公開再生数とエンゲージビューは別の指標で、Shortsの公開再生数には再生開始やリプレイが含まれる。[検索と発見のヒント](https://support.google.com/youtube/answer/11914225?hl=ja) · [Shortsの作成と再生数](https://support.google.com/youtube/answer/10343433?hl=ja) · [YouTube Studioの指標](https://support.google.com/youtube/answer/12942217?hl=ja)
- 維持率グラフの山は再視聴や共有で生じることがあり、分かりづらくて見直された可能性もある。谷は離脱やスキップの候補。Shortsは動画内のフレームをサムネとして選択できる。[視聴者維持率](https://support.google.com/youtube/answer/9314415?hl=ja) · [Shortsの作成](https://support.google.com/youtube/answer/10343433?hl=ja)

**推測（49秒のカンナエを起点にした試作値）**

| 時間 | 画・音・字幕 |
|---|---|
| 0〜1秒 | 1フレーム目から変形・発見の瞬間。次の五稜郭なら四角の輪郭に星形が重なる。冒頭からずんだもんの声を出し、音なしでも形と短い字幕で主題が分かるようにする。 |
| 1〜3秒 | 「幕府の城が、なんで星形なのだ？」のように、画を指す名詞と疑問を置く。質問は最後の模型1カットで答えられる粒度にする。 |
| 3〜10秒 | 固有名と時代を短く置く。俯瞰で対象を認識させ、赤青なら記号やラベルも添える。 |
| 10〜38秒 | 中盤は3区切り程度。位置、変化、結果を各8〜10秒ほどで見せ、2〜4秒ごとに移動・点灯・寄りなど画に意味のある変化を入れる。形の比較中は同じ角度を4〜6秒維持してよい。 |
| 38〜46秒 | 最初の問いに1文で答える。字幕2行は1行目に主題、2行目に変化や比較を置く。数は1画面に1組まで。重要な年や寸法は1.5〜2秒以上出し、単位も同時に見せる。 |
| 46〜49秒 | 冒頭と同じ構図・ズームに戻す。結論はその手前で言い切り、同じ環境音の上で切って再開に接続する。 |

**推測（検証）**　基本は45〜52秒。答えの絵が一つなら40〜45秒、史料の違いを説明する場合は55〜60秒まで。ずんだもんの声を前にし、切り替わりに小さな効果音を添える。字幕は説明対象にかからず、右側・下端のUIから離して配置。投稿後は同じ経過日数でカンナエと比較し、まず視聴を選んだ割合、次に3秒付近と中盤の谷、最後に平均視聴時間・平均再生率を見る。冒頭だけ弱ければ次作の最初の絵を変更し、中盤だけ弱ければ数字や地名が重なった区間を短くする。ループは試作上の工夫として扱い、その効果は公開再生数だけで判断しない。

## 4. 次の5本

以下はすべて**推測（制作案）**。台詞はオリジナル。年・寸法・隻数・形状は末尾の資料に基づく。すべて縦9:16、箱庭とずんだもんの声、字幕最大2行を前提にする。

### 1本目｜なぜ五稜郭は星形？ 幕府の城を真上から（48秒）

1. **0〜3秒**　真上の星形が一瞬で発光。「幕府の城が、なんで星形なのだ？」
2. **3〜8秒**　斜め俯瞰にして「箱館・五稜郭」と表示。
3. **8〜15秒**　地面、堀、城郭を順に表示し、平地の城であることを見せる。
4. **15〜23秒**　真上で外周をなぞり、5つの突角を1つずつ点灯。
5. **23〜32秒**　古図を参照した輪郭に切り替え、突角が砲台となるよう設計されたことを説明。
6. **32〜41秒**　1857→1864を年表に出し、幕府が築いた洋式城郭と回収。
7. **41〜48秒**　斜め俯瞰から真上へ戻し、冒頭と同じ星形を再表示。

使う数字は突角5つ、1857〜1864年。設計の経緯と形は公文書館の古図・解説。[国立公文書館「函館五稜郭の図」](https://www.archives.go.jp/exhibition/digital/koubunshonosekai/contents/01.html)

### 2本目｜大阪城の地下に、もう一つの石垣（49秒）

1. **0〜3秒**　いまの大阪城の箱庭から地面が透け、地下の石垣が光る。「大阪城の下に、秀吉の石垣があるのだ！」
2. **3〜9秒**　地上と地下を横断面で色分け。「地上」「地下」の短いラベル。
3. **9〜16秒**　豊臣期に時計を戻し、石垣を組み上げる。
4. **16〜22秒**　1615年を表示。夏の陣で落城したことを城のシルエットで示す。
5. **22〜33秒**　1620年、徳川幕府が再築を開始。新しい地表を重ねる。
6. **33〜43秒**　地下の石組みへ寄り、発掘された豊臣期の石垣と説明。
7. **43〜49秒**　同じ断面から現在の地表へ戻り、地面が透ける冒頭につなぐ。

使う数字は1615年と1620年。断面の深さは概念図とし、実測値は扱わない。[大阪城天守閣「豊臣石垣館」](https://www.osakacastle.net/toyotomi_stone_wall/index.html)

### 3本目｜黒船4隻、蒸気船は何隻だった？（45秒）

1. **0〜3秒**　浦賀沖を俯瞰。4隻のうち2隻にだけ煙。「この黒船、全部が蒸気船だと思うのだ？」
2. **3〜8秒**　「1853年・浦賀沖」と出し、艦隊全体の輪郭を保つ。
3. **8〜15秒**　蒸気船2隻を寄りで表示。船名は画面に短く添える。
4. **15〜22秒**　帆船2隻に切り替え、さきほどと同じ角度で比較。
5. **22〜31秒**　「蒸気船2＋帆船2」を同じフレームで表示。煙は船種を見分ける模型の記号。
6. **31〜39秒**　船から海岸へ視点を動かし、来航の目的が大統領の親書を届けることだったと説明。
7. **39〜45秒**　4隻揃った冒頭の俯瞰に戻す。

使う数字は1853年、4隻の内訳2＋2。編成と来航の背景を掲載。[横須賀市「ペリーの黒船」](https://www.city.yokosuka.kanagawa.jp/2752/uraga_walk/kurohune.html)

### 4本目｜長崎・出島は本当に扇形だった？（46秒）

1. **0〜3秒**　海面上に扇形の輪郭が現れる。「この扇、長崎にあった人工島なのだ！」
2. **3〜9秒**　カメラを引き、長崎港と島の位置を見せる。
3. **9〜17秒**　1636年。海面から人工島を持ち上げ、当初はポルトガル人を住まわせるためだったと説明。
4. **17〜24秒**　俯瞰で約1万3,000㎡を表示。扇の弧を一筆でなぞる。
5. **24〜34秒**　1641年。オランダ商館が平戸から移ったことを地図上のラベル移動で示す。
6. **34〜41秒**　町と島を同じフレームで見せ、日本と欧州の貿易・文化交流の場になったと回収。
7. **41〜46秒**　建物の表示を薄くして、冒頭の扇形の輪郭を残す。

使う数字は1636年、1641年、約1万3,000㎡。形の由来を追加する場合は別途史料確認。[長崎県「出島和蘭商館跡」](https://www.pref.nagasaki.lg.jp/bunkadb/index.php/view/87)

### 5本目｜ローマの神殿、屋根から入った雨はどこへ？（47秒）

1. **0〜3秒**　ローマのパンテオンの断面で、屋根の円い穴から雨が落ちる。「この神殿、屋根から雨が入るのだ。どこへ行く？」
2. **3〜9秒**　外観へ短く引き、建物名を表示。
3. **9〜17秒**　内部を横断面に変え、円形広間の直径と床からの高さがともに約43.3mと表示。
4. **17〜25秒**　真下から丸い開口部を見上げ、視線を水滴に合わせる。
5. **25〜34秒**　床へ寄って排水孔を点灯。22個という数字を一枚で表示。
6. **34〜41秒**　屋根の開口と床の排水孔を同じ断面に収め、雨の行き先を回収。
7. **41〜47秒**　雨音を続けたまま冒頭と同じ断面へ戻す。

使う数字は広間の直径・高さ43.30m、床の排水孔22個。排水孔の配列は概念図で示す。[ローマ国立博物館局「パンテオンの歴史」](https://direzionemuseiroma.cultura.gov.it/en/pantheon/historical-background/)
