# 声なし物理・数学ショートのための気持ちいい効果音

## 1. 心地よさの定義

### 事実

「快い／不快」は聴き手の評価。ラウドネス、シャープネス、ラフネスなどは、評価に関わり得る知覚の側面。たとえば同じ音程の組み合わせでも、協和音への好みは文化集団によって異なる。したがって単一の数値で音の快さを決めるのは難しい。 [McDermott ほか、2016](https://www.nature.com/articles/nature18635)

| 観点 | 研究・規格から言えること |
|---|---|
| ラウドネス | 音の主観的な大きさ。周波数やレベルなどで変わる。ISO 226の等ラウドネス曲線は正面からの定常純音で得た条件付きの基準で、短い複合音の補正値に直接は使えない。ISO 532-1には時間変動音も扱う推定法がある。 [ISO 226](https://www.iso.org/standard/83117.html)・[ISO 532-1](https://www.iso.org/standard/63077.html?browse=ics) |
| シャープネスと刺さり | シャープネスは高い帯域に知覚上の重みを置く音色指標。2〜5 kHzは刺さる打音を点検する範囲の目安。黒板を引っかく音などの研究では、約2〜4 kHzの成分が不快さに寄与した。帯域全体を一律に削る根拠にはならない。 [DIN 45692の計算仕様](https://devdocs.ansys.com/dpf/dpf-framework/operator-specifications/sound/compute_sharpness_din45692/)・[Reuter・Oehlerによる研究解説](https://acoustics.org/pressroom/httpdocs/162nd/Oehler_4pPP6.html) |
| ラフネスとうなり | 近い周波数の部分音は、加算されると周波数差に応じて振幅が変動する。ゆっくりしたうなりは個々の揺れを追える。速く深い変調はざらつきとして知覚されることがある。叫び声の研究では30〜150 Hzの時間変調が目立った。この範囲は振幅が揺れる速さ。 [Plomp・Levelt、1965](https://www.mpi.nl/world/materials/publications/levelt/Plomp_Levelt_Tonal_1965.pdf)・[Arnal ほか、2015](https://pubmed.ncbi.nlm.nih.gov/26190070/) |
| 協和・不協和 | 単純な2音では周波数差と聴覚の臨界帯域が協和判断と関係する。複合音では基音の音程に加え、部分音同士も干渉する。非整数倍の部分音はガラスや金属の質感を作る設計に使えるが、近接する強い成分を長く残すとラフネスが増え得る。 [Plomp・Levelt、1965](https://www.mpi.nl/world/materials/publications/levelt/Plomp_Levelt_Tonal_1965.pdf) |
| アタック | 立ち上がり時間や冒頭の過渡成分は音色や発音動作を識別する手掛かり。映像では、近づく2点が交差する瞬間の効果音が、すれ違いと衝突の見え方を変えた実験もある。 [Timbre Perception Test](https://pmc.ncbi.nlm.nih.gov/articles/PMC7536169/)・[Sekuler ほか、1997](https://www.nature.com/articles/385308a0) |

ASMRの調査では、低めで複雑な音、ゆっくり細部を見せる映像が有力な誘因として報告された。音の特徴から分析した別研究では、ぞくぞくする感覚と快さを別々に評価している。ASMRでの反応をそのまま高密度なシミュレーションへの好みに当てはめることはできない。雨音のような音の集合では、各音より集合の特徴が知覚される場合がある。 [Barratt ほか、2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5633022/)・[ASMRと快さの比較研究、2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11444235/)・[McDermott・Simoncelli、2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC4143345/)

### 推測・この動画での評価基準

- **気持ちいい音**は、映像を見ていると接触や頂点が音でも分かり、反復しても音量を下げたくならず、材質や動きの違いが聞こえる音。
- 壁に当たる瞬間は3〜8 ms程度の滑らかなアタックを起点にする。ガラスなら短い非整数倍成分で「カラン」を残し、胴鳴りを基音寄りにする。たとえば3 kHz付近だけが刺さるなら、まずその部分音を3〜6 dB弱めて元音と比較する。頂点には丸いはじき音、接近には短い上昇音を当てると、動きごとに耳で区別しやすい可能性がある。
- ASMRからは、音と画面上の細部を同期させること、手触りを示す小さな過渡成分、密集の前後に空白を置くことを借りる。視覚の接触時刻に音の開始を置いてから、耳で感じる立ち上がりを確認する。パッドの遅いアタックは接近の予兆や場面転換向き。

## 2. 毎秒数十音のミックス

### 事実

定常な発音率を `r`、実効的に聞こえる余韻を `T` 秒とすると、平均の重なりは概ね `r × T`。毎秒40音なら100 msで4音、300 msで12音。位相が無相関で各音のパワーが同程度ならパワーは概ね加算され、同相の音では瞬間振幅が足し合わさる。音を重ねたときは帯域の競合で弱い音が隠れることもある。完成音の番組ラウドネスとトゥルーピークの測定法はITU-R BS.1770に定義されている。 [聴覚マスキングの実験例](https://www.nature.com/articles/s41467-019-12893-0)・[ITU-R BS.1770-5](https://www.itu.int/rec/R-REC-BS.1770-5-202311-I/_page.print)

### 推測・初期設定

| 項目 | 試す値と処理 |
|---|---|
| 音階と音域 | 疎な区間はCメジャー・ペンタトニックの C/D/E/G/A（半音差 0/2/4/7/9）。密集時は C/E/G（0/4/7）、最密時は C/G（0/7）を起点にする。基本は C4〜C5（約262〜523 Hz）。低域は根音と5度を優先。五音音階にも全音の隣接があり、非整数倍部分音の重なりは和音だけでは解消しないので、基音の配置と音色を一緒に調整する。 |
| 全きっかけを発音 | 密集時は木琴などを使い、主要部分音の時定数を15〜25 ms程度に短縮。時定数20 msなら80 msで振幅が約-35 dBになり、毎秒40音で実効的に約3.2音が重なる。強い衝突だけ明るいアタックを使い、その他もそれぞれの時刻で小さく鳴らす。同時刻に同音色・同音程が重なるなら、同じ波形を多数足す場合のピークを見込んでそのグループのゲインを下げる。 |
| 同時発音の上限 | イベントの省略が許される場合は余韻の実効同時発音を4〜6音から試す。上限時は強い衝突を優先し、弱い既存音の余韻を5〜10 msでフェードして枠を空ける。1イベント1音を維持する場合は主音の余韻にだけ枠を使い、超過分は10〜25 msの小さな短音にする。同時発生が上限を超える場合、この方式でもアタックの絶対数は超える。 |
| 密度と音量 | 波形を足す段階で直近100 msの実効重なり数 `N` をもとに、基準2音として `min(1, sqrt(2 / max(N, 1)))` をゲインの起点にする。密集の直前から約20 msで下げ、密集後150〜300 msで戻す。オフラインならイベント時刻から先読みできる。波形が揃うピークには別途ヘッドルームを確保し、最終書き出しでトゥルーピークを確認する。試作の上限は-1.5 dBTPを候補にする。 |
| 音高補正 | 音色ごとに低・中・高を同じ再生ゲインで確認し、たとえばA4より上を1オクターブあたり-2 dB（最大-4 dB）から試す。高音が弱く聞こえる音色では補正を浅くする。2〜5 kHzの特定の部分音だけが突出する場合は、その成分を先に落とす。 |
| 残響 | 20〜40音/秒ではドライ、または残響のウェット信号を直接音より24 dB程度下げる。疎な区間はウェットを-18 dB程度、RT60を0.2〜0.35秒、残響側のローパスを2.5〜3 kHzから試す。アタックと次のイベントが埋もれたらウェット量と余韻を下げる。 |
| 左右 | 画面の横位置を -1〜+1 に正規化して `p = 0.25 * x`。等電力パンは `theta = pi*(p+1)/4`、L/Rゲインは `cos(theta)` / `sin(theta)`。イベントごとのパンを固定し、スマホのモノラルでも衝突と頂点が判別できるか確認する。 |

**推測・比較方法**　同一映像の疎な5秒と密な5秒を使い、現行のガラス音、短い木の音、両者を使い分けた版を用意する。再生時に聴感上の音量をそろえ、順番を入れ替えて各版を3周。スマホスピーカーとイヤホンで「繰り返し聴きたい」「刺さらない」「映像のきっかけが分かる」を別々に5段階で採点する。長さと音量を一度に変えると選好の理由を追いにくいので、差が分かりにくければ片方ずつ調整する。

## 3. NumPyによる単音レシピ

**推測・試作用の設計値**　実物を測定した値ではなく、質感を作り分けるための合成値。部分音は `周波数比 / 相対振幅 / 減衰時定数(ms)`。時間包絡は振幅 `exp(-t/τ)` で、時定数1回で約-8.7 dB。アタックと末尾20 msのフェードは半コサイン。フィルター欄は各部分音の定常周波数 `f` に掛ける2次バターワース・ローパス形の重み `1/sqrt(1+(f/fc)^4)` の `fc`。カットオフで約-3 dB。水滴でも重みは定常周波数で固定する。

| 音色・関数 | 部分音 | アタック / LP / 長さ |
|---|---|---|
| ガラス `glass` | 1/1/78、2.32/.34/43、4.16/.24/25、5.43/.15/15 | 4 ms / 2600 Hz / 450 ms |
| ベル `bell` | .5/.25/175、1/1/165、1.20/.23/95、1.50/.18/72、2.03/.17/45、2.62/.13/30 | 8 ms / 2300 Hz / 920 ms |
| マリンバ `marimba` | 1/1/65、4/.37/24、9.9/.16/10 | 5 ms / 2200 Hz / 410 ms |
| カリンバ `kalimba` | 1/1/110、2.02/.27/55、3.08/.19/32、5.05/.11/15 | 6 ms / 2500 Hz / 600 ms |
| 木琴 `xylophone` | 1/1/28、3/.52/15、6.2/.24/8 | 2.5 ms / 3200 Hz / 200 ms |
| 水滴 `water_drop` | 1/1/49、2/.26/26、3.1/.11/16 | 4 ms / 2000 Hz / 320 ms |
| 柔らかいパッド `soft_pad` | 1/1/250、2/.24/220、3/.13/175、4/.06/125 | 85 ms / 1400 Hz / 1200 ms |
| オルゴール `music_box` | 1/1/125、2/.42/65、3/.23/38、4.06/.14/26、6.75/.13/14 | 3 ms / 3000 Hz / 720 ms |

水滴だけ全モードを定常周波数の64%から上昇させる。瞬時周波数の比は `1 - 0.36*exp(-t/0.018)`（`t` は秒）。ベルには `f0` より低いモードも含む。各関数は `f0`（Hz）と `sr` を受けてモノラルの浮動小数点配列を返す。WAVは C5相当（523.251 Hz）、48 kHz、16-bit PCM、モノラル、両端50 msの無音、サンプルピーク-12 dBFS。試聴用のピーク合わせなので、音色間の聴感上の音量には差があり得る。NumPyがあるPythonで、作業フォルダから `python3 -B study/sound/recipes.py` を実行すると `samples/` に再生成できる。

## 4. 動画ごとの変え方

**推測・抽選の単位は動画ごと**　動画IDを乱数シードにして「音色セット、音階、主音、残響」を抽選し、選んだ値も記録する。編集で一部のイベントを追加しても既存の音が変わらないよう、各イベントの細かな揺らぎには動画IDと固定イベントIDを使う。

| 候補セット | 衝突 / 頂点 / 接近 | 音階と残響 |
|---|---|---|
| 木の音 | マリンバ / 木琴 / 水滴 | メジャー・ペンタトニック、基本ドライ |
| ガラスの音 | ガラス / カリンバ / 水滴 | メジャー・ペンタトニック、疎な区間だけ短い残響 |
| 金属の音 | オルゴール / カリンバ / ベル | マイナー・ペンタトニック（0/3/5/7/10）、ベルは疎な区間で使う |

**推測・抽選の制約**　主音はC/D/E♭/Fから選び、各音を概ねC4〜C5に折り返す。疎な残響はドライと短い残響の間で抽選し、密集時は表のミックス設定を優先する。密集時のマイナー側は根音/短3度/5度、最密時は根音/5度。マリンバや木琴の短い音を密集区間の主役にして、パッドは接近の予兆など間隔の空いたイベントに使う。動画内の音色の役割を固定し、物理量から音を選ぶ場合は、衝突速度をアタックの音量、頂点の高さを音階内の音高へ割り当てる。偶然性を加えるなら、音量の±1 dB程度から始める。
