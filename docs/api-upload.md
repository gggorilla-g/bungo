# API投稿の運用（2026-10-30〜）

- Googleの審査は10/30に受付終了（「APIで上げた動画は自動で非公開にならない」との回答）。同日、予約公開・すぐ公開ともに、雑学・ホー博士・妄想科学で公開を確認。
- 仕組み：.github/workflows/yt_upload.yml（tools/short_upload.py。videos.insert と thumbnails.set だけ。審査で約束した範囲）。
  - 動画は制作の実行（nazo_short / nazo）の成果物から取る（run_id と artifact と glob）。手元で作った動画は一時ブランチ upload-tmp に置いて取る（使い終わったら消す。Claudeからはブランチを消せないので、ゲンタさんに頼む）。
  - 100MBを超える手元の動画は、upload-tmp に90MBずつ（<名前>.mp4.partaa, .partab …）置く。yt_upload.yml がつないで上げる（10/31追加）。
  - 投稿キット（【タイトル】【説明】【タグ】）とサムネのパスを渡す。publish_at を空にするとすぐ公開、UTC日時を入れると予約公開。
  - 結果は投稿キットと同じフォルダの api_upload_*.txt。
  - サムネ設定に失敗しても投稿は止めない（警告を残す）。
  - 説明欄はAPIで5000バイトまで（日本語は1文字3バイト）。長尺の写真クレジットは短くまとめる。
- 鍵（GitHub Secrets）：雑学 YT_REFRESH_TOKEN、ホー博士 YT_REFRESH_TOKEN_NAZO、妄想科学 YT_REFRESH_TOKEN_MOSO（10/30登録）、百物語 YT_REFRESH_TOKEN_KAIDAN（10/31登録）。

- ショートと長尺のつなぎ（関連動画）はAPIにないので、ClaudeがゲンタさんのChromeでStudioを操作して設定する（10/30 ゲンタさん「やっていいと思う」）。電話番号の確認があるチャンネル（ホー博士）だけ。

## 電話番号の確認がないチャンネルの制約（2026-10-31 確認）

- 確認がないのは雑学と妄想科学。確認があるのはホー博士。百物語は未確認。
- 電話番号1つで確認できるのは1年に2チャンネルまでで、枠を使い切っている。
- 使えないもの（ゲンタさんがStudioから操作しても同じ）：
  - 15分を超える動画。上げても「処理を中止しました／動画が長すぎます」になる（雑学の長尺 782AgWasLWg で発生）。
  - カスタムサムネ（thumbnails.set が403）。
  - ショートの関連動画。
- Studioの「動画から選択」は、YouTubeが自動で選んだ3コマしか出ない。好きなコマは選べない。動画の先頭や最後にサムネの絵を入れる方法は効かない（10/31、雑学の長尺で確認）。
- 対応：
  - 長尺は14分台までにする（目標14:30〜14:45）。
  - ショートから長尺へは、説明欄の先頭の「本編はこちら → URL」でつなぐ。
  - 入口ショートの音声は「関連動画から」ではなく「説明欄から」と言う。
  - 自動で選ばれる3コマに強い絵が来るよう、写真の大きいカットを多めにする（推測：選ばれ方は分かっていない）。
- 10/31 ゲンタさん：別の番号での確認は「難しそうです」。電話番号の確認なしで続ける。
  - 長尺は、どのコマが選ばれてもサムネとして通る画面にする（写真を大きく、太い字幕を常に出す）。
  - 投稿後に3コマを見て、いちばん強いものを選ぶ。
- 確認済み（中級者向け機能あり）はホー博士と百物語。gorilla GG（個人）はなし（10/31、設定の「機能の利用資格」で確認）。
- 百物語を雑学に作り替える案は、ゲンタさん「百物語が勿体無いですね」で見送り（10/31）。
- 動画の冒頭にサムネの絵を入れる案もやめる（10/31 ゲンタさん「じゃあやめましょう」）。
- 決定（10/31）：雑学と妄想科学は、ショート中心の運用に総集編（長尺）を足す形にする。
  - 総集編は既存ショートをまとめたもので、15分未満（14:45まで）にする。
  - サムネは自動で選ばれる3コマから選ぶ。
  - ショートから総集編へは説明欄のリンクでつなぐ。
  - 新作の長尺（10選のような書き下ろし）は作らない。
