# Privacy Policy / プライバシーポリシー

This application ("BUNGO") is a private automation tool operated by the owner of this repository.
It uses the YouTube Data API only to upload videos and manage playlists on the owner's own YouTube channels.

- It does not collect, store, or share any personal data of other users.
- OAuth credentials are stored only as encrypted GitHub Actions secrets of this repository.
- No data is sold or provided to third parties.
- The owner can revoke access at any time from https://myaccount.google.com/permissions

This application uses YouTube API Services. See the YouTube Terms of Service (https://www.youtube.com/t/terms)
and the Google Privacy Policy (https://policies.google.com/privacy).
