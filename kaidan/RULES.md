# 今晩の百物語（怪談）の決まりごと

- ターゲット: 寝る前に音だけで聞く人（中心）、作業中に流す人、古典の怪談・民話が好きな人。驚かせたい層は狙わない。
- 音: 驚かせる音は使わない。効果音はさりげない既定の音。BGMは展開ごとに3曲を切り替え、音量は一定にそろえる。
- サムネ: 静かな型（暗く沈めた絵＋明朝の縦書きの題名＋朱の「第〇話」）。煽り文句は入れない。題名そのものを大きく。
- タイトル: 【怪談朗読】題名（原作者）｜今晩の百物語 第〇話。題名は検索される言葉なので言い換えない。
- 名乗り: 古典の怪談では「信じるか信じないかはあなた次第」は言わない（第二話から）。都市伝説の回だけ入れる。
- 語り: 原作（青空文庫・権利切れ）を、いまの言葉で語り直す。実話として語らない。概要欄に「実話ではありません」。
- 読み: 固有名は yomi_words で読みを明示。2つの読み上げ方式で読みが割れた文は必ず確認（src/yomi_gate.py）。
- 公開: 夜21〜23時。数話をつないだ1時間前後のまとめ回も出す。
