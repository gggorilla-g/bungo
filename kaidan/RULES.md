# 今晩の百物語（怪談）の決まりごと

- ターゲット: 寝る前に音だけで聞く人（中心）、作業中に流す人、古典の怪談・民話が好きな人。驚かせたい層は狙わない。
- 音: 驚かせる音は使わない。効果音はさりげない既定の音。BGMは展開ごとに3曲を切り替え、音量は一定にそろえる。
- サムネ: ほどよいインパクトの型（kaidan/thumb_mid.py）。絵を右に大きく明るめに＋左の暗がりに、上からチャンネル名→朱の札「第〇話」と作者→題名（いちばん大きく）→話の中の一言（台本の thumb_copy、2行の一文）。一言は「場面だけ見せて、何が起きるかは言わない」一文（例「誰もいない墓の前で、／男は毎晩、琵琶を弾いていた。」）。台本のあらすじにある事実だけで書く。罫線・「閲覧注意」などの煽り文句、「殺す」など暴力的な語は使わない（広告制限を避ける）。切り抜きの中心は thumb_focus。
- タイトル: 【怪談朗読】題名（原作者）｜今晩の百物語 第〇話。題名は検索される言葉なので言い換えない。
- 名乗り: 「今宵も、ようおこしやす。語り部の、宵狐でございます。…この世とあの世の境、〇〇へ、ご案内いたします。」京ことばは頭のあいさつ「ようおこしやす」だけ。〇〇は台本の kojo_place（無ければ「この世とあの世の境へ」）。「信じるか信じないか」は言わない。語りでは「第〇話」と言わない（第三話から）。題名カード・サムネ・YouTubeのタイトルには出す。
- 語り: 原作（青空文庫・権利切れ）を、いまの言葉で語り直す。実話として語らない。概要欄に「実話ではありません」。
- 読み: 固有名は yomi_words で読みを明示。2つの読み上げ方式で読みが割れた文は必ず確認（src/yomi_gate.py）。
- 画: ごくゆっくりの横パンだけ（毎秒7px、寄り引きなし）。同じ画像が続く間は文をまたいで動きがつながり、カットに見せない。画像を替えるのは話の場面が変わるときだけ。
- 章のアイキャッチ: 暗い地に章題が静かに浮かんで消える（3.2秒）＋遠くの鐘「ぼーん」。枠・傾き・弾みは使わない。
- 効果音: 不協和のさりげない短い音（短2度・増4度など）。BGMの音量は第一話と同じ（既定0.09）。イヤホンでちょうどよいと確認済み。
- 公開: 夜21〜23時。数話をつないだ1時間前後のまとめ回も出す。

- 話の終わり: 最後の一文のあと3.5秒の間を取り、その間に3秒かけてゆっくり暗転→暗いまま1.5秒→語り部が暗がりから浮かび上がる（1.6秒）。締めの最後は「それでは、また次の夜に。この世とあの世の境で、お待ちしております。」で、静かに暗くなって終わる。
- ここぞという一文: 台本のセクションに "hush": [その文に含まれる語]。声を低く・ゆっくりにし、BGMを止める（直前0.5秒で消え、あと3秒で戻る）。1話に2〜3か所まで。第三話から。

## 読み（10/31 追加）
- 読み間違いは視聴者が一気に萎える。1語でも出したら事故として扱う。
- 読みの関門（src/yomi_gate.py）は3つ目の見張りを持つ：読みが2通りある語（角・表・〜者・〜場・〜方 など）は、2つの読み上げエンジンが同じ読みでも全部止める。台本の yomi_words に読みを書くまで在庫に積めない。
- 10/31 の事故5語（角カク、表ヒョウ、風呂場フロジョウ、大胆者・ふとどき者のシャ）は、2つのエンジンが同じ間違いをして関門をすり抜けた。
- 投稿の前に、漢字の語を1語ずつ読みと並べた表で確かめる（雑学・妄想科学・ホー博士も同じ関門を通る）。

## サムネ（11/1 ゲンタさん「めっちゃ怖い感じにしてもいい」「もっと怖くしてもいい」）
- kaidan/thumb_mid.py の既定は style="scary"：色を抜いて青緑に寄せ、絵の中心（thumb_focus）だけを青白く残して周りを闇に沈める。うっすらずれた二重像と粒子。血・傷の表現は使わない。
- 作り直しは kaidan_thumb.yml（ids に作品IDを空白区切り）、差し替えは yt_thumb.yml（動画ID=サムネのパス、thumbnails.set のみ）。
- 11/1 第一話〜第十一話の全サムネを怖い版に差し替え済み。
