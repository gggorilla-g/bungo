# 依頼1｜長尺「ずんだもん惑星探査隊」第1回

## 1. 総合評価

企画の方向性は良い。特に「科学を解説する」のではなく「ずんだもん自身が科学現象を体験し、ひどい目に遭う」という設計が差別化の中心になる。

ただし、現状のv3には以下の課題がある。

1. 冒頭が説明中心で、最初の数秒に視覚的な引きが不足している。
2. 7惑星がほぼ同じ構成で続き、中盤に単調さが生まれる。
3. 一部の科学的説明に不正確な表現がある。
4. GMが進行役にとどまり、キャラクターとしての面白さが不足している。
5. ランキングの評価基準が曖昧。

改善方針は、冒頭5秒に惨劇を先出しし、7惑星を一つの任務として構成すること。

GMは「科学的には正しいが、任務の進め方が理不尽」というキャラクターにする。

## 2. 科学的事実の修正

【水星】
・昼側の最高気温約430℃、夜側約−180℃は概ね正確。
・水星の太陽日は約176地球日。
・自転周期は約58.6地球日なので混同しない。
・昼と夜はそれぞれ約88地球日続くという説明が可能。ただし地点によって日照条件は異なる。

【金星】
・地表温度は約465℃。
・地表気圧は約92気圧。
・地球の海の水深約900mに相当する圧力。
・硫酸の雲は存在するが、硫酸の雨が地表まで降るわけではない。
・自転周期約243地球日、公転周期約225地球日。
・「自転周期が公転周期より長い」が正確。「太陽が昇ってから次に昇るまでの1日」は約117地球日。

【火星】
・平均気温約−60℃。
・地表気圧は地球の約0.6％。
・重力は地球の約38％。
・同じ初速度で跳ぶ場合、理想条件では地球の約2.6倍の高さまで跳べる。
・「宇宙服なしで必ず15秒で気絶」は断定しない。急減圧・低圧環境に関する知見から、十数秒程度で意識を失う危険があると表現する。

【木星】
・体積は地球の約1,321倍。
・立つことができる固体表面はない。
・重力約2.4倍は基準となる大気圧面での値であり、地表の重力ではない。
・深部に進むにつれて圧力と温度が上昇する。

【土星】
・平均密度は約0.69g/cm³で水より小さい。
・巨大な水槽に浮くという話は、平均密度を説明するための思考実験。
・環は無数の氷や岩石などの粒で構成されている。
・環は固体の板ではない。
・土星本体にも立てる固体表面はない。

【天王星】
・自転軸の傾きは約98度。
・公転周期は約84地球年。
・極付近では約42年間の昼と約42年間の夜に相当する長い日照周期がある。
・全地点で42年間昼夜が続くわけではない。
・大気で約−224℃という極低温が観測されている。
・固体の地表温度として紹介しない。

【海王星】
・太陽から最も遠い惑星。
・風速2,000km/hを超える強風が観測・推定されている。
・新幹線の最高速度320km/hと比較すると約6.25倍。
・固体の地表はない。

【全体の設定】
・地球以外の7惑星を調査する設定は正確。
・冥王星は現在、準惑星に分類されている。
・宇宙服なしでは大半の惑星でまともな探査が成立しないため、GMが各惑星の環境を疑似体験させる設定を採用する。
・疑似体験装置やデフォルメされた被害描写はフィクション。
・惑星の数値と科学現象は実際の知見に基づく。

## 冒頭30秒

冒頭は説明ではなく、金星での惨劇から始める。

0:00〜0:05

0:05〜0:18

視聴者に「なぜこんなことになったのか」「最もひどい星はどこなのか」という2つの疑問を持たせる。

## 中だるみ対策

・水星と金星で危険な世界観を提示。
・火星では一度希望を見せ、期待を裏切る。
・木星では「地面がない」という意外性。
・土星では環に乗れないという視覚的な笑い。
・天王星では42年間という時間のスケール。
・海王星では風による派手なアクション。
・最後に主観的なワーストランキングを発表。

木星と土星が同じ「地面がない」という結末になるため、土星は環の構造を中心にする。

## GMのキャラクター

GMは、低く静かな声で淡々と理不尽な命令をする。

・科学的な説明は正確。
・必要な情報を後出しする。
・ずんだもんの抗議に動じない。
・予算には異常に厳しい。
・毎回「移住、不可」と判定する。

## ショート4本

### 1. ブラックホールで麺になる

A：
「ブラックホールに落ちると、ずんだもんは麺になるのだ」

B：
「体が縦に伸びて横につぶれる、宇宙で最悪の落下」

科学的注意：
潮汐力によるスパゲッティ化は実際に考えられる現象。ただし、強烈な潮汐力を受ける位置はブラックホールの質量によって異なる。

### 2. 地球の穴

A：
「地球を貫く穴に落ちたら、ずんだもんは焼き枝豆になるのだ」

B：
「地球の中心まで落ちたら、何が起こる？」

科学的注意：
地球内部は高温高圧。実際には穴を維持すること自体が困難。空気抵抗や壁の崩壊など、仮定を明示する必要がある。「必ずぺしゃんこになる」とは断定しない。

### 3. タイムマシン

A：
「1時間前に戻ったずんだもん、宇宙で迷子になるのだ」

B：
「タイムマシンに位置指定がなかったら？」

科学的注意：
時間移動は実証されていない。宇宙に放り出されるという結果は、座標の扱いを仮定したフィクションであり、確立した科学的事実ではない。

「科学的に本当のことだけ」というチャンネル方針を厳守するなら、現状のままでは採用不可。

### 4. 月の消失

A：
「月が消えたら、ずんだもんの世界はどうなる？」

B：
「月がなくなると地球は壊れるのか？」

科学的注意：
月の消失は潮汐や地球の自転軸の長期安定性などに影響を与えると考えられる。

ただし、月が消えると直ちに灼熱と極寒を繰り返し、化石になるという説明は不正確。

「焼けて凍って化石」は現時点では不採用。

# 5. チャンネル全体の運用戦略

## ショートの役割

新規視聴者を獲得する。

基本構成：
1. 冒頭0〜2秒でひどい結末を宣言。
2. 科学的な条件を説明。
3. 被害を2〜3段階でエスカレート。
4. 最後に結果を回収。

基本コピー：
「もしも〇〇したら、ずんだもんは△△になるのだ」

## 長尺の役割

キャラクターとシリーズへの定着を促す。

基本構成：
1. 冒頭で惨劇を先出し。
2. GMが任務を提示。
3. ずんだもんが実際に体験。
4. 科学的な数値を見せる。
5. 理不尽な判定を受ける。
6. 最後に任務の結果を回収。
7. 次回の任務を予告。

## 総集編の役割

動画ライブラリーを活用し、長時間視聴の入口を作る。

企画例：
「ずんだもんが宇宙で遭遇した最悪の現象まとめ」
「太陽系で最も危険な場所ランキング」
「ずんだもんが科学の実験でひどい目に遭った総集編」
