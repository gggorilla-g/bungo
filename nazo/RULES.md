# NAZO 台本の規約（在庫仕込み時にClaudeが従う）

チャンネル: 歴史・古代・自然の未解決の謎を約8〜10分で整理する。ずんだもん（VOICEVOX）、黒×赤。
運用: BUNGOと同じ在庫方式。台本はチャットで書き、Actionsは在庫から動画化と投稿だけを行う（実行時にLLMを呼ばない）。

## 線引き
- 事実（年代・数字・地名・固有名詞・寸法）は `nazo/state/texts/<id>.json` のWikipedia本文（日英）に書かれていることだけ。
  数字・カタカナ語・「」引用は `nazo/check.py` が機械照合し、本文に無ければ不採用。漢字の事実は書き手が自分で裏取りする。
- 説は自由に紹介してよいが、必ず「〜という説」「〜と考える人もいる」の形。どれが正しいか断定しない。
- 人名: 没後100年以上の歴史上の人物だけ名前を出す。近年の研究者・存命者は名前を出さず、説の中身で語る。
- 題材: 現代の実在人物・事件の被害者や遺族が関わるものは扱わない。宗教や民族を貶める説は紹介しない。
- 禁句（`check.py` の NG_PHRASES）: 真相は／正体は／宇宙人／陰謀 など、断定・煽り・誤情報に寄る言い回し。

## 構成（`check.py` が順序を検査）
1. toi（謎）: 挨拶なし。1文目から。世間の思い込みを名指し→本文の事実で覆す（BUNGOの「裏切り」構造）→問い。
2. jijitsu（わかっていること）: 1〜2パート。物としての事実、記録の事実。
3. setsu（説）: 2〜4パート。冒頭で声が「ここから先は、説の話です。」と宣言する（自動挿入）。各説の弱点も添える。
4. shin_toi（残る問い）: 答えを言わない。誰でも次に一歩踏み出せる行動（公開資料を見る等）で終える。

## 文体
- 静かに語りかける。煽らない。流れる語り（前の文が次の文を呼ぶ）。短い言い切りと長めの説明を交ぜる。
- 1文は字幕1枚になる。60字前後までに収める。
- 合計2200〜4300字。見出しは15字以内、チャプター名として並べて引きになる言葉に。

## 仕込み手順
1. `python nazo/stock.py check <id> nazo/drafts/<id>.json` で照合とカナを確認
2. 誤読は台本をかなに開くか、`nazo/drafts/<id>_yomi.json` に {原文の文: 読み上げ文} で修正
3. `python nazo/stock.py push <id> nazo/drafts/<id>.json nazo/drafts/<id>_yomi.json`
