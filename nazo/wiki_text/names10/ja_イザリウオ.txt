カエルアンコウ（学名：Antennarius striatus）は、アンコウ目カエルアンコウ科に属する魚。


== 形態 ==
体長は20センチメートルを超える。体は球体状で、口は大きく上向きで、前方に存在する。皮膚は柔らかく伸縮可能で、糸状の細かい突起が不規則に存在する。体色を環境に合わせて変化させることができるため、個体差が大きい。黄色や茶色がかった橙色の個体が多いが、緑色、灰色、茶色、白色、黒色の個体も存在する。体と鰭には、暗色の縞模様または細長い斑点があり、眼から放射状に延びる縞模様を持つ個体もいる。
背鰭の第一棘から発達した誘引突起が存在し、前方を向いている。先端には擬餌状体（エスカ）が存在する。背鰭は棘条2 - 7本で構成される。ボンボリカエルアンコウ (Antennarius hispidus) とは模様や体色、皮膚の突起などが似ているが、疑餌状体の形状で見分けることができる。誘引突起は背鰭第二棘と同じ長さで、暗色の縞模様がある個体が多い。背鰭第二棘は垂直で、可動である。背鰭第三棘は体後方へ向いている。背鰭第二、第三棘は背鰭と分離している。胸鰭は前足のように発達している。


== 生態 ==
水深219メートルより浅場の砂底、砂泥底、岩場、サンゴ礁に生息する。通常水深40メートル程の場所でみられる。
泳ぎが苦手な底生魚であり、胸鰭と腹鰭で海底を歩くように移動する。普段は単独で生活するが、繁殖期には集まる。 呼吸とともに口から水を取り込み、胸鰭後方の鰓穴から勢いよく排出することで、素早く前方に進む。環境に合わせて数週間かけて体色を変え、周囲のサンゴや海綿に擬態する。捕食者を避けるためにイソギンチャクやウニなどに擬態するベイツ型擬態も行う。水を吸い込んで体を膨らませ、捕食されにくくする防御行動が知られている。
カエルアンコウ科全体に言えることだが、本種はかなり貪欲な肉食魚で、目の前を食べる獲物をすべて食べようとする。通常は小型の魚や甲殻類を捕食するが、共食いも観察されている。自分と同じ大きさの獲物であっても飲み込むことができる。本種はカエルアンコウ科の中では珍しく、夜間でも化学誘引物質を使い捕食行動をする。

擬餌状体は捕食者に目立ってしまうため、捕食時以外は短くしている。擬餌状体を生物のようにアーチ状や小刻みに動かして獲物を引き付けた後、口を普段より大きく開け、0.006秒という速さで獲物を水ごと吸い込む。


== 分布 ==
伊豆諸島、小笠原諸島、北海道から九州南岸の日本海・東シナ海沿岸、瀬戸内海、宮城県から九州南岸の太平洋沿岸。
浙江省から海南島の中国沿岸、インド洋から中央太平洋までの熱帯および亜熱帯海域、ハワイ諸島、大西洋のアフリカ西海岸、ニュージャージー州沿岸からメキシコ湾を含むブラジル南部沿岸、カリブ海に分布する。地中海と北極海では見られない。


== 分類 ==
亜種は特に知られていない。


== 人間との関わり ==
特に利害のある種ではないが、色合いが綺麗であること、這うような動きが魚としては珍しいこと、疑似餌を使って獲物をおびき寄せることなどが興味深いことから水族館などで飼育することがある。


== 名前 ==
日本魚類学会では2020年現在、魚類に厳密に標準和名を定めていないが、「カエルアンコウ」が事実上の標準和名に相当する名前として広く使われ、この名前を使う図鑑や目録が多い。後述のように和名としては比較的新しいものであるが、『日本産魚類検索：全種の同定 第3版』（2013）などはこの名前で掲載されている。
元々の標準和名は「イザリウオ」であり図鑑や目録に広く使われていたが、差別的な名称だということで変更された。同学会が標準和名制定の参考にするとしている『日本産魚類検索：全種の同定Ⅱ 第2版』（2000年）でも「イザリウオ」で掲載されていたが、本種は例外的にこの名前を採用せず「カエルアンコウ」に変更された。その後前述のように『日本産魚類検索』も改訂に合わせて第3版から「カエルアンコウ」に変更されている。改名は同科近縁種全体で行われており、接尾語に「イザリウオ」と付いていた種は原則として前半の接頭語は変えずに後半部分を「カエルアンコウ」に変更している。
「イザリウオ」の理由は諸説あるが、その一説に本種が体を引きずるようにゆっくり歩く様子由来の命名で、足が不自由な人が体を引きずるように動く様を指す「躄る」「躄り」から来ているというものがある。実際に本種の漢字表記は「座魚」が少し見られる以外には「躄魚」が当てられることが多かった。「漁り」をする魚だから「漁魚」であるという説もあり、学会でもこの説と類似の意方言名の存在は理解していたが、前述の漢字表記、およびルアー行為の発見と発表が漢字表記よりもかなり後であるということから、「イザリウオ」の意味は「漁魚」ではなく「躄魚」であり、差別的な命名であると判断して和名の変更に踏み切っている。
方言名は多数知られており、アケジロ、アゴモフグ、アゲジロ、アンコ、アンコウ、ツリンボ、サンボテ、ウオツリボウズ、トラアラカビ、ハタアラカビ、トラアラカキ、ハタアラカキ、カエルボッカ、モイオ、モクギョなどがある。
種小名 striatusは「縞のある」という意味、属名 Antenanariusは「触角を持ったもの」という意味でいづれも形態的特徴に基づく名前である。


== カエルアンコウ科 ==

カエルアンコウ科は世界に14属51種、日本に4属15種が知られている。以下は日本での例。

ハナオコゼ属 - ハナオコゼ
カエルアンコウモドキ属 - カエルアンコウモドキ、ベニカエルアンコウ
カエルアンコウ属 - カエルアンコウ、イロカエルアンコウ、クマドリカエルアンコウ
ソウシカエルアンコウ属 - ソウシカエルアンコウ
